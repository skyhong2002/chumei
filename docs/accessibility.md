# 文字連結與鍵盤操作

共用樣式讓主要內容段落、清單與說明項目內的文字連結持續顯示底線；按鈕樣式的連結仍維持按鈕外觀。鍵盤焦點使用 2px 實線外框與 3px 外距，不只依賴背景或陰影辨識。

搜尋與限動對話框開啟時會移入焦點，Tab / Shift+Tab 留在可見、可操作的控制項之間；關閉後焦點回到開啟按鈕。Escape 可從搜尋結果或限動控制項關閉對話框。限動的左右方向鍵切換內容，按鈕上的空白鍵保留原生啟動行為。

## 驗收步驟

1. 對首頁、活動總覽、限動、訂閱、未登入帳號與系統狀態頁分別套用明暗主題，執行 axe 的 `link-in-text-block` 規則。訂閱頁 RSS 介紹／GitHub 文件，以及登入說明連結都應為零違規。
2. 以 Tab 聚焦 RSS 介紹連結，確認未懸停時已有底線，聚焦時有清楚外框。
3. 聚焦搜尋按鈕並按 Enter，輸入關鍵字，確認焦點起於搜尋欄；Shift+Tab 與 Tab 可循環，Escape 關閉並回到搜尋按鈕。
4. 聚焦活動篩選按鈕並按 Enter，確認 `aria-pressed` 更新且焦點可見。
5. 聚焦限動按鈕並按 Enter，確認焦點移至關閉按鈕；Shift+Tab / Tab 可循環、方向鍵可切換、Escape 關閉後回到同一限動按鈕。
6. 在 390px 手機視窗，以 Enter 展開更多選單並 Tab 到第一個選項，確認焦點外框可見。

2026-09-23 在隔離資料與匿名登入頁中，以 Chromium / Playwright 完成以上驗收，六頁 × 明暗主題的文字連結規則皆為零違規。這不等於完整螢幕閱讀器或所有 WCAG 規則的合規認證。
