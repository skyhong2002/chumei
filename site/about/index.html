關於竹梅

「竹梅」取自梅竹賽的梅（清華，梅貽琦）與竹（交大，凌竹銘），倒過來唸——因為我們把兩校的活動放在同一邊。

竹梅是獨立的校園活動觀測站，自動彙整公開資訊：兩校公告系統、NYCU LIFE、學生社團的公開 Instagram 貼文。活動欄位由 AI 從貼文與海報擷取，標示「待確認」者請以原始貼文為準。

資料來源

完整的來源清單（含每個社團帳號與收錄數）在 資料來源索引。主要類別：

  • 陽明交大校園公告系統（演講課程、藝文體育、其他活動）
  • 清華大學各單位公告：課外活動指導組、藝術文化總中心、校級公告、體育室 等
  • NYCU LIFE 官方活動 API
  • 兩校學生社團與單位的公開 Instagram 帳號（80+）與 Facebook 專頁（69）

內容回報與下架

資訊有誤、活動想上架、或您是主辦單位希望調整／移除內容，請到 GitHub Issues 回報（有活動投稿與錯誤回報的表單範本），我們會盡快處理。

特別感謝

竹梅站在這些開放專案與公開資料的肩膀上：

  • NYCU Maps（nycu-life）— 光復校區建築量體與校界資料、地圖視覺的參考
  • NYCU LIFE — 官方活動 API 與 設計系統
  • RSSHub — 萬物皆可 RSS，社群來源的抓取骨幹
  • Instaloader — Instagram 限時動態擷取
  • MapLibre GL JS — 地圖渲染引擎
  • OpenStreetMap 貢獻者 — 清大校園建築資料（ODbL）
  • 內政部國土測繪中心 — 臺灣通用電子地圖圖磚
  • Apify — Facebook 公開專頁抓取
  • Caddy — 網站伺服器

給社團的話

你們的活動被收錄了嗎？想置頂、修改資訊或提供第一手活動資料，歡迎聯繫我們——讓活動被更多清交人看見。
