關於竹梅

「竹梅」取自梅竹賽的梅（清華，梅貽琦）與竹（交大，凌竹銘），倒過來唸——都有梅竹了，怎麼能沒有竹梅呢？

竹梅是獨立的校園活動觀測站，自動彙整公開資訊：兩校公告系統與單位網站、NYCU LIFE 官方活動，以及學生社團的公開 Instagram、Facebook、Threads、X 貼文與 IG 限時動態。活動欄位（時間、地點、費用、是否報名）由 AI 從貼文與海報擷取並經程式驗證。

程式碼由 Claude Code（Fable 5）以及 Codex（5.6 Sol）透過 T3 code 完成，以 MIT 授權開源——歡迎自由修改與散佈。

你可以用貼文河道看最新動態、在活動總覽用地圖與篩選找活動、用日曆排行程、到機構名錄看每個社團的頁面，或透過 Telegram 頻道與自訂 RSS／行事曆訂閱接收更新。

資料來源

完整的來源清單（含每個社團帳號與收錄數）在 資料來源索引。主要類別：

  • 陽明交大校園公告系統（演講課程、藝文體育、其他活動三個分類）
  • 清華大學各單位公告（RPage）：課外活動指導組、藝術文化總中心、體育室、住宿書院、國際處、校級公告 等八個站
  • 陽明交大藝文中心官網與 NYCU LIFE 活動 API
  • 兩校社團與單位的公開 Instagram／Facebook／Threads／X 帳號約三百個，以及 IG 限時動態（完整清單與收錄數見名錄）

內容回報與下架

看到活動想讓它上竹梅？到回報活動頁把貼文或公告的連結貼上（要先登入）。系統會自動判讀是不是清交相關的活動：新活動直接收錄、已經有的幫你對上、不確定的留給站長看，處理進度公開顯示在同一頁。

資訊有誤、或您是主辦單位希望調整／移除內容，同樣到回報活動頁貼上活動頁連結並在備註說明，我會盡快人工處理。登入支援陽明交大 OAuth 與 Google 帳號（清大朋友請用 Google 登入），也可來信 chumei@observe.tw。網站程式本身的問題才請到 GitHub Issues。

特別感謝

竹梅站在這些開放專案與公開資料的肩膀上：

  • NYCU Maps（nycu-life）— 光復校區建築量體與校界資料、地圖視覺的參考
  • NYCU LIFE（社團）— 設計系統
  • RSSHub — 萬物皆可 RSS，社群來源的抓取骨幹
  • Instaloader — Instagram 限時動態擷取
  • MapLibre GL JS — 地圖渲染引擎
  • OpenStreetMap 貢獻者 — 清大校園建築資料（ODbL）
  • 內政部國土測繪中心 — 臺灣通用電子地圖圖磚
  • Apify — Facebook 公開專頁抓取
  • Caddy — 網站伺服器
  • NYCU LIFE 與 HAIX Lab — 提供運算資源
  • Telegram — 不用付錢就能做 Bot 推播；也拜託 LINE 更開放更好用一些
  • GitHub — 感謝它剛好在我開發的時候穩定，不然的話可能就不想開發了呵呵
